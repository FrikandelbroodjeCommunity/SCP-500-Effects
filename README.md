# About SCP-500 Effects

A LabAPI plugin that spawn additional SCP-500 instances which give custom effects.

Possible effects:

- `Ops` - Lets you see all players through walls, like SCP-1344.
- `'Drink me'` - Shrinks your body after consuming it.
- `Santa` - A pill of luck, gives a random item, good or bad.
- `Shadow` - Lets you pass through doors unseen, like a true shadow.
- `Sonic` - Gives extreme speed.
- `Super` - Eat this to move faster and walk silently, but you lose the use of your hands.

> [!IMPORTANT]
> **Required dependencies:**
> - [FrikanUtils](https://github.com/FrikandelbroodjeCommunity/FrikanUtils/blob/master/FrikanUtils/README.md)

Install the dependencies above, together with
the [latest release](https://github.com/FrikandelbroodjeCommunity/SCP-999-LabAPI/releases/latest) and place them in your
LabAPI plugin folder.

# Config

The config only contains the messages displayed to the user.
